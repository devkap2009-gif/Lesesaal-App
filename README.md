# Lesesaal – Android-App

Öffnet die Lern-App **Lesesaal** (Lesen, Lernen, Schreiben mit Claude) als eigene App auf Android.

## APK herunterladen
Unter **Releases → latest** liegt immer die neueste `Lesesaal.apk`. Auf dem Handy herunterladen, öffnen und die Installation erlauben („Aus dieser Quelle installieren“).

## Wie es funktioniert
Die App ist eine Trusted Web Activity: Sie startet den Lesesaal über Chrome. Dadurch bist du automatisch mit deinem claude.ai-Konto angemeldet, und alle Claude-Funktionen, die Synchronisierung und deine Bibliothek funktionieren wie im Browser.

Jeder Push auf `main` baut die APK automatisch neu (GitHub Actions).
